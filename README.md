# Lost-and-Found-Campus-App

Lost & Found Campus is a Flutter-based mobile application designed to help students report, search, and recover lost items on campus.

## Features

- Report lost items
- Report found items
- Add item details
- Add location and date
- Search lost and found items
- View item details
- Contact the owner/finder
- Mark items as returned

## Technology

- Flutter
- Dart
- Firebase
- Git
- GitHub
